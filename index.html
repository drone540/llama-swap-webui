      CORS / connection help
      
llama-swap's native endpoints (/health /running /profiles /metrics /logs) send no CORS headers, so browsers block them when the page is cross-origin (including file://). Chat & /v1/* endpoints proxy through and work fine. For full System-tab functionality, run the bundled zero-dependency proxy next to this file:
python serve.py --upstream http://192.168.1.22:8080 --port 8000
then open http://localhost:8000 and set API Base URL to http://localhost:8000 (same origin = no CORS involved).
